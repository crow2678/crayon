# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, assume good intent. Harassment, personal
attacks, and discriminatory language are not welcome.

Report unacceptable behavior privately via a GitHub security advisory or by
emailing the maintainers (see `SECURITY.md`).
